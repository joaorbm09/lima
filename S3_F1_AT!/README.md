# Documentação da atividade S3_F1_AT1
---
#### Nesta atividade tivemos a proposta de fazermos uma aplicação em html, onde construimos uma aplicação basica e logo depois fizemos algo mais comlexo onde tivemos que implementar mais coisas
---
**1. Introdução**
---
Nesta pasta ou neste repositório, estamos esibindo uma pagina de site com deferentes acessos dentro dele.

---

**2. Página principal**
---
O "index.html" é parte principal do meu codigo onde estou mostrando as principais informações do meu site, contendo titulo, imagem, descrição, acesso por link, e botão.

---
**3. Página completmentar 1**
---

O "index1.html", é o arquivo que utilizei para definir o link de acesso do "index.html", onde esta falando sobre o lugar de atendimento do meu site.

---
**4. Página complementar 2**
---
O "index2.html", eu utilizei este arquivo para acesso do botão de "fale conosco!".

 **Adendo!:**
     Os arquivos "index1.html e index2.html" contem um botão, que assim que ele é selecionado ele automaticamente voltara para a página principal "index.html.

---
**6. Tabela de tags utlizadas**
---

| Elemento | Categoria | Finalidade |
| :--- | :--- | :--- |
| **`header`** | Flow | Define o cabeçalho superior da página ou de uma seção. |
| **`h1`** | Heading | Título principal da página. |
| **`main`** | Flow | Representa o conteúdo principal e exclusivo da página. |
| **`section`** | Sectioning | Agrupa conteúdos relacionados em uma seção genérica. |
| **`div`** | Flow | bloco para agrupamento e organização do código. |
| **`p`** | Flow / Phrasing | Define um parágrafo de texto. |
| **`b`** | Phrasing | Deixa o texto em negrito. |
| **`img`** | Embedded | Inserção e exibição de imagens na página. |
| **`a`** | Interactive | Cria hiperlinks para navegação entre páginas e arquivos. |
| **`button`** | Interactive | Botão clicável para acionar interações ou eventos. |
