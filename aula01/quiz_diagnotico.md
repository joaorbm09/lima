# Quiz diagnotico

**O que significa HTML?**

    A sigla HTML significa HyperText Markup Language ou Linguagem de marcação de hipertexto. De maneira direta podemos dizer que o HTML como o esqueleto de uma página. Ele define o que é título, páragrafo, imagem, botão, link e entre outros. 
    Se você abrir o código-fonte de qualquer site (basta apertar Ctrl + U no navegador), vai ver várias tags como <h1>, <p>, <img> e <a>. São esses elementos que dizem ao navegador como mostrar o conteúdo.


**Quem criou a Web?**

    A World Wide Web (Web) foi criada pelo cientista da computação britânico Tim Berners-Lee em 1989. Na época, ele trabalhava no CERN (Organização Europeia para a Pesquisa Nuclear) e criou a Web para facilitar o compartilhamento de informações e documentos entre cientistas de diferentes universidades e institutos ao redor do mundo.

    Tim contribuiu com:
        - HTML (HyperText Markup Language): A linguagem usada para criar e estruturar páginas web.
        - HTTP (Hypertext Transfer Protocol): O protocolo que permite a transferência de dados e páginas na internet.
        - URL (Uniform Resource Locator): O sistema de endereços usado para localizar recursos e páginas na rede.

    Um detalhe interessante a ser ressaltado que muitos confundem internet e web. A Internet é a infraestrutura de redes de computadores conectadas (criada décadas antes, com a ARPANET), enquanto a Web é o sistema de páginas e documentos interconectados que roda por cima dessa rede.

**Quais são os três pilares da Web?**

    HTML: 
        A sigla HTML significa HyperText Markup Language ou Linguagem de marcação de hipertexto. De maneira direta podemos dizer que o HTML como o esqueleto de uma página. Ele define o que é título, páragrafo, imagem, botão, link e entre outros. 
    
    HTTP:
        O Protocolo de Transferência de Hipertexto (HTTP) é a base da internet e é usado para carregar páginas web usando links de hipertexto. O HTTP é um protocolo da camada de aplicação desenvolvido para transferir informações entre dispositivos em rede e é executado no topo de outras camadas da pilha de protocolos de rede.
    
    URI: 
        O URI (Uniform Resource Identifier) é um identificador único que é utilizado para localizar recursos na internet. Ele é composto por duas partes principais: o esquema (scheme) e o identificador específico do recurso. O URI é essencial para identificar recursos de forma única e desempenha um papel fundamental na arquitetura da web.
    



**O que é hipertexto?**

    Hipertexto é um texto em formato digital que contém blocos de informações interconectados por links (hiperlinks). Em vez de uma leitura linear (do início ao fim, como num livro), ele permite que o leitor escolha seu próprio caminho ao clicar nos links, navegando entre diferentes páginas, imagens ou vídeos.
    como exemplos de : 
    - Sites
    - Vídeos
    - Imagens
    - Documentos
    - Redes sociais

**O que é HTML5?**

    HTML5 é a versão mais recente e moderna da linguagem HTML, usada para estruturar páginas da Web.Ele trouxe novas tags semânticas (como header, article, section, footer), suporte nativo a áudio e vídeo, uso de <canvas> para gráficos, e melhor integração com CSS e JavaScript para criar sites mais rápidos, responsivos e interativos.

**Qual grupo iniciou o desenvolvimento do HTML5?**

    Em 2004, as empresas Apple, Mozilla e Opera se uniram e criaram o grupo WHATWG (Web Hypertext Application Technology Working Group) para continuar o desenvolvimento da versão 5 do HTML. Depois, o W3C passou a colaborar e também trabalhou em especificações do HTML5, mas o impulso inicial veio do WHATWG.

# Atividade de apropriação

| Ano | Versão | Principais Características | Impacto / Inovação |
| :--- | :--- | :--- | :--- |
| **1989** | **Criação da Web** | Proposta inicial de Tim Berners-Lee no CERN para compartilhar informações via hipertexto. | Nascimento da World Wide Web (WWW). |
| **1991** | **HTML Inicial** | Primeira versão pública ("HTML Tags") contendo apenas 18 elementos simples. | Permitia a criação de documentos básicos com texto e links (*hyperlinks*). |
| **1997–1999** | **HTML 4 / 4.01** | Introdução do suporte a folhas de estilo (**CSS**), formulários avançados, tabelas e scripts (**JavaScript**). | Separação inicial entre conteúdo (HTML) e design (CSS); início da web interativa. |
| **2000** | **XHTML 1.0** | Reescrita do HTML sob as regras estritas do **XML** (tags obrigatoriamente fechadas e em minúsculas). | Foco na padronização rígida e rigor sintático, tornando o código mais previsível. |
| **2014** | **HTML5** | Introdução de tags semânticas (`<header>`, `<nav>`, `<article>`), suporte nativo a áudio/vídeo e APIs avançadas. | Fim da dependência de plugins externos (ex: *Flash*); suporte total a dispositivos móveis e aplicações web modernas. |
