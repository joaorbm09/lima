## 📌 1. Visão Geral do Repositório

Este repositório registra os trabalhos e projetos práticos desenvolvidos na disciplina de **LIMA (Linguagens de Marcação)**. A matéria foca nos pilares fundamentais da World Wide Web, arquitetura de páginas web com **HTML5 Semântico**, inserção de mídias, navegação interativa via hiperlinks, acessibilidade e estruturação de interfaces web modernas.

---

## 🚀 2. O Que Foi Desenvolvido Até Agora (Progresso Atual)

### 📚 Tópicos e Práticas Concluídas:

1. **Fundamentos da Web & Quiz Diagnóstico (`aula01/quiz_diagnotico.md`):**
   - Estudo da história da Web e contribuição de **Tim Berners-Lee** (CERN, 1989).
   - Diferenciação conceitual entre **Internet** (infraestrutura de rede) e **Web** (sistema de documentos e hiperlinks).
   - Compreensão dos 3 Pilares da Web:
     - **HTML** (*HyperText Markup Language*): Estrutura e esqueleto das páginas.
     - **HTTP** (*Hypertext Transfer Protocol*): Protocolo de comunicação e transferência.
     - **URI/URL** (*Uniform Resource Identifier/Locator*): Endereçamento de recursos na rede.

2. **Estruturação Básica e Mídias (`aula02` e `aula03`):**
   - Construção de documentos HTML com tags de cabeçalho (`<h1>` a `<h6>`), parágrafos (`<p>`) e negrito (`<b>`).
   - Inserção de imagens localmente (`<img>`) com atributos de redimensionamento (`width`, `height`) e texto alternativo de acessibilidade (`alt`).
   - Agrupamento de elementos com divisores de bloco (`<div>`).

3. **HTML5 Semântico & Portais Corporativos (`aula04` & `S3_F1_AT!`):**
   - Uso de tags semânticas para melhor indexação e acessibilidade:
     - `<header>`: Cabeçalho principal da página ou seção.
     - `<nav>`: Menu de navegação por âncoras (`#sobre`, `#cursos`, `#noticias`).
     - `<main>`: Conteúdo principal da aplicação.
     - `<section>` & `<article>`: Agrupamento temático e blocos autônomos.
     - `<aside>` & `<footer>`: Conteúdo complementar e rodapé.
   - Projeto prático **HighTech** (School e Portal de Negócios) integrado com páginas de atendimento (`index1.html`), formulário/fale conosco (`index2.html`) e navegação completa.
   - Mapeamento categórico das tags utilizadas em tabela documental (Categories: Flow, Heading, Phrasing, Embedded, Interactive, Sectioning).

### 🛠️ Tecnologias e Ferramentas Utilizadas:
- **HTML5 (Tags Semânticas, Formulários e Links)**
- **Markdown (Documentação Diagnóstica e Tabelas)**
- **VS Code / Live Server**

## 💻 4. Como Executar e Testar

### Pré-requisitos:
- Qualquer navegador web moderno (Google Chrome, Mozilla Firefox, Microsoft Edge).

### Passo a Passo:

1. **Abertura Direta:**
   - Navegue até as pastas do repositório no seu computador e dê um duplo clique em qualquer arquivo `.html`, tais como:
     - [`/aula04/portal_empresa.html`](./aula04/portal_empresa.html)
     - [`/S3_F1_AT!/index.html`](./S3_F1_AT!/index.html)

2. **Via VS Code + Live Server (Recomendado):**
   - Abra a pasta do repositório no VS Code.
   - Instale a extensão **Live Server**.
   - Clique com o botão direito no arquivo `index.html` e selecione **"Open with Live Server"**.
